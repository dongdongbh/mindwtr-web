# 重复任务

对于完成后应再次出现的工作，请使用重复任务，例如回顾、家务、日常例行事项、续期和维护任务。

重复规则位于任务编辑器中。如果使用快速记录，请先创建任务，再打开编辑。

## 设置重复任务

1. 打开任务。
2. 编辑任务。
3. 在时间安排部分找到**重复**字段。
4. 选择**每天**、**每周**、**每月**或**每年**。
5. 调整重复细节。
6. 保存任务。

桌面端和移动端的任务编辑界面都会显示重复控件。

## 重复选项

| 选项 | 适用事项 |
| --- | --- |
| **每天** | 习惯与每日例行事项。 |
| **每周** | 每周回顾、会议、杂事或维护。 |
| **每月** | 账单、月度回顾、订阅或月度检查清单。 |
| **每年** | 年度续期、税务、登记和纪念日。 |

每种重复类型都可通过**每隔**跳过一定间隔，例如每 2 周或每 3 个月。

每周任务可选择具体工作日。每月任务可在每月同一天重复，也可使用**自定义**设置特定星期几等模式。

## 固定日程还是完成后重复

默认情况下，Mindwtr 保持固定日程。适用于应始终与日历日期绑定的截止事项或承诺。

示例：

- 每月交房租。
- 每月第一个星期六检查财务。
- 每年续保险。

如果下一项任务应根据当前任务实际完成的时间安排，请开启**完成后重复**。

示例：

- 浇水后 3 天再次浇花。
- 完成清洁后 2 周再次清洁过滤器。
- 上次跟进后 1 个月再次跟进。

当完成后重复还指定了星期几或每月某一天时，下一项任务会落在间隔最后一周（或一个月）中第一个匹配日期。“每 2 周的星期日”若在星期二完成，会在下下个星期日再次出现，而不是紧接着的星期日。

如果任务实际较早完成，但之后才标记为已完成，请改用实际完成时间（桌面端右键点击完成按钮；移动端长按状态菜单中的**已完成**），下一次任务便会从真正完成的时间开始安排。

## 结束重复

使用**结束**控制系列何时停止：

| 设置 | 含义 |
| --- | --- |
| **永不** | 每次完成后继续创建下一项任务。 |
| **指定日期** | 下一次发生时间超过所选日期时停止。 |
| **次数** | 达到所选发生次数后停止。 |

## 日历预览

一个重复系列只保留一项活跃任务。完成当前任务时，Mindwtr 才创建下一项真实任务。

如果希望提前规划整个系列，请开启**在日历中显示未来重复**。日历会在可见的月、周或日程范围内显示每一次发生——每日任务会填满每个可见日期。这些预览有助于规划，但不是额外的活跃任务。

## 完成后会发生什么

完成重复任务后，Mindwtr 会创建下一项任务，保留相同的标题、项目、领域、情境、标签、备注、提醒和其他任务详情。下一次的检查清单项目会被重置。

如果任务有截止日期、开始日期或回顾日期，Mindwtr 会按重复规则推进这些字段。仅含日期的值仍保持仅含日期。

如果任务完成得晚，下一项任务仍保持原有节奏：它会落在完成时刻之后的第一个周期上，中间错过的次数会被跳过，而不是堆积成一串逾期副本。每周一重复的任务拖到周三完成，下一次仍是下周一。开始、截止和回顾日期会一起推进，保持你设定的间隔。

在日期到来前，下一项任务不会出现在专注和下一步行动中。未来开始日期会像往常一样推迟任务；没有开始日期的重复任务会推迟到下一个日期（截止日期和回顾日期中较早者）。这样，刚创建的下一项不会在你完成当前任务后立刻重新出现在列表里。已推迟的任务仍可在**项目**和**搜索**中找到。

这一规则从重复任务存在的那一刻起就生效，而不仅限于完成后生成的下一项。一次性任务在截止日期到来之前仍然可见，方便你提前处理；重复任务则把同一个日期当作它应当重新出现的日子——因此两个截止日期相同的任务，只要其中一个是重复任务，在专注中的表现就可能不同。想让重复任务提前出现，请为它设置开始日期：从那天起它会出现在专注和下一步行动中，同时保留截止日期。
