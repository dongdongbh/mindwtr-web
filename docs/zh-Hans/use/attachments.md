# 附件（文件、链接、音频）

Mindwtr 允许你为**任务**和**项目**添加文件与链接。附件是可选功能；启用同步后，附件也会跨设备同步。

---

## 可以附加什么

- **文件**（PDF、图片、文档等）
- **链接**（URL、网页、参考链接）
- **音频笔记**（启用“保存音频附件”时）
- 桌面端启用 Obsidian 集成后可附加 **Obsidian 笔记**

---

## 添加附件

### 桌面端

- 打开任务或项目。
- 在**附件**中点击**添加文件**或**添加链接**。
- 也可以把文件从文件管理器拖到已打开的任务编辑器上来添加附件。
- 添加链接时，粘贴 URL 或本地文件路径。
- 对于任务附件，只有启用 Obsidian 集成后才会显示**附加 Obsidian 笔记**。

### 移动端

- 打开任务。
- 使用**添加附件**选择文件或添加链接。
- 如果你录制语音记录且已启用**保存音频附件**，音频笔记会自动添加。

### 副本与链接

- **添加文件**会把文件副本存入 Mindwtr 自己的存储。即使原文件之后被移动、重命名或删除，附件仍可使用。移除附件会删除 Mindwtr 的副本，不会删除原文件。
- **添加链接**只保存一个指针。如果想引用文件而不复制，请粘贴 URL 或本地文件路径（桌面端也可使用**链接到文件…**浏览选择）。文件移动后路径链接会失效，这是链接的正常行为。
- 每个附件行都会显示类型：回形针表示 Mindwtr 持有文件副本，链接图标表示它是指针（工具提示会显示完整目标）。
- v1.1.0 之前在桌面端添加的文件附件引用原始路径，而不持有副本（显示链接图标）；重新附加即可转换为副本。
- **附件文件不包含在 JSON 备份中。** 备份只保存每个附件的元数据和路径；在桌面端，副本本身位于 `mindwtr.db` 旁的 `attachments` 文件夹，你需要单独复制该文件夹。请参阅[备份与恢复](/zh-Hans/data-sync/backup-restore)。

## 音频附件

启用**保存音频附件**（设置 → 常规）后，Mindwtr 会在转录文本旁保留原始语音笔记。如果之后想重听或分享录音，这会很有用。

### Linux 音频播放依赖

Linux 上的音频播放使用 **GStreamer**。如果看到 `autoaudiosink not found` 等错误，请安装 GStreamer 插件：

**Arch / Manjaro**
```bash
sudo pacman -S gstreamer gst-plugins-base gst-plugins-good gst-plugins-bad gst-plugins-ugly gst-libav
```

**Debian / Ubuntu / Mint**
```bash
sudo apt install gstreamer1.0-plugins-base gstreamer1.0-plugins-good gstreamer1.0-plugins-bad gstreamer1.0-plugins-ugly gstreamer1.0-libav
```

**Fedora**（部分编解码器需要 RPM Fusion）
```bash
sudo dnf install gstreamer1-plugins-base gstreamer1-plugins-good gstreamer1-plugins-bad-free gstreamer1-plugins-ugly gstreamer1-libav
```

## 同步行为

- 附件元数据随任务/项目同步。
- 实际文件在元数据之后同步。
- 附件并不是一次性快照：附加之后再编辑该文件，新内容会随同步传播。每轮同步都会检查它接触到的文件的修改时间和大小是否变化，并用内容哈希确认确实发生了改动，然后重新上传该文件，其他设备再重新下载。
- 对**链接**（外部路径）文件的改动检测优先在桌面端提供。手机在所有后端都会重新下载已更新的文件，但只能检测应用自有存储中文件的自身改动，且仅限文件同步、WebDAV 和 iCloud。
- 如果两台设备在同步前编辑了同一个文件，则按整个文件的“最后写入者胜出”解决：较晚的编辑会覆盖较早的编辑，文件内部不做任何合并。
- 如果本地缺少文件，附件仍会显示，并可在文件可用时重新下载。
- 清理操作会检查当前设备已知的引用。如果另一台设备尚未同步，共享的远程附件文件不会进行全局引用计数。

> 提示：大文件会拖慢同步。请尽量使用较小的附件，或改用链接。

---

## 清理

Mindwtr 会清理**失去关联的附件**（不再被任何任务/项目引用的文件）。清理会移除本地副本和同步元数据。WebDAV 等支持版本化删除的后端也可以删除远程对象。

- 桌面端：也可在**设置 → 数据 → 附件清理**中手动运行。
- 移动端：同步期间自动运行清理。

文件同步会在清理后把不可变的附件版本保留在共享文件夹中，因为进度较慢的设备可能仍引用这些文件。这可以保护附件数据，但文件夹可能会随时间增长。如需释放空间，请先在文件系统中复制整个共享同步文件夹（包括 `data.json` 和 `attachments/`），并将副本存放在同步服务之外。让所有设备完成同步后，再删除已确认过时的版本。不要删除其他 Mindwtr 同步文件或无法识别的版本。
