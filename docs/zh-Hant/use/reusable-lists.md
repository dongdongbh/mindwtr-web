# 可重複使用的清單（範本）

Mindwtr 支援可重複使用的檢查清單，適合沒有嚴格排程但會反覆執行的任務（例如打包、採買或行前準備）。

## 三種做法

### 複製（範本）

每次執行都需要一份全新副本時使用。

範例：**打包清單**

1. 在「將來/也許」中保留一項主範本任務
2. 規劃旅行時複製它
3. 編輯副本而不影響主範本

複製時會重設：

- 所有檢查清單項目恢復為未勾選
- 清除完成狀態；已完成或已封存任務的副本會進入**收件匣**，等待重新釐清
- 副本不會進入「今日專注」
- 不複製檔案附件；連結會一併複製
- 副本成為全新任務，並取得新的檢查清單與附件 ID

會保留的內容：標題、描述、專案、區段、領域、情境、標籤，以及開始、到期和回顧日期。重複任務會保留其規則，但會開啟獨立的循環序列，因此完成其中一份不再推進另一份。

### 重設檢查清單

想再次使用同一份清單時使用。

範例：**採買清單**

1. 購物時逐項勾選
2. 點選**重設檢查清單**
3. 下次繼續使用

重設會：

- 取消勾選每個檢查清單項目
- 直接更新原任務，而不建立第二份副本
- 若任務已標示完成，則重新開啟

### 複製專案（多任務範本）

當範本是整個專案而非單一檢查清單時使用。

範例：**客戶導入**

1. 保留一個包含區段與任務的主範本專案
2. 有新客戶時複製該專案
3. 在副本上進行，主專案維持不變

複製專案會重設的內容：

- 副本命名為 `<Project> (Copy)`，排在同一領域的最後，且不處於聚焦狀態
- 每個複製的任務都回到**下一步**（參考任務仍為參考），並清除開始、到期、回顧與完成日期
- 複製任務中的檢查清單項目從未勾選開始，也不會進入今日聚焦
- 專案及其任務上的附件都會一併複製，並在下次同步時重新上傳

會保留的內容：專案的備註、領域、標籤、顏色與狀態，以及完整的區段結構——每個任務都會回到原本的區段。專案自身的到期日與回顧日期會原樣保留——不同於任務上的日期，它們不會被清除，因此請在副本上確認。已刪除的任務與區段不會被複製。

## 在哪裡操作

- **行動版**：任務編輯器 → **複製任務**或**重設檢查清單**
- **桌面版**：任務動作選單。「已完成」與「已封存」中的任務列在游標停留時也會顯示複製按鈕。
- **專案**：桌面版在側邊欄按右鍵點選專案，或使用專案標題列中的**複製**。行動版將專案列向右滑動，或使用專案詳細頁中的**複製**。

## 如何選擇

- 旅程準備、新手引導清單，或每次執行都應保留各自筆記與時程的事項，請使用**複製任務**。
- 購物、例行維護，或同一項任務能長期沿用的清單，請使用**重設檢查清單**。
- 若清單還包含日期、重複規則或專案專屬筆記，複製通常較安全。

## 提示

- 將主範本放在**將來/也許**或干擾較少的專案中，以免塞滿日常清單。
- 經常複製的範本任務可取名為 `打包清單（範本）` 等一眼可辨的名稱。
- 若清單中的每一項開始需要各自的截止日期或重複規則，請拆成獨立任務，不要讓一份可重複清單承擔過多用途。
