需要 Mindwtr 的幫助嗎？

從這裡開始。取得幫助的最佳方式取決於你的需要——問題和功能建議最適合在 GitHub 上跟進，私人問題可以發郵件。想為專案出份力？也有很多免費的方式。

報告問題或提出疑問。

報告問題或尋求幫助的最佳去處是 GitHub issue——日誌、裝置資訊和後續跟進都集中在一個可追蹤的地方，不會丟失。請附上你的平台和應用版本（設定 → 關於），這樣更容易幫到你。

  • 提交 GitHub issue

    最適合報告問題和提功能建議——公開、可搜尋、可追蹤，不會有遺漏。

    提交 issue →

  • 從應用內傳送反饋

    已經在用應用了？在「關於」頁面（設定 → 關於）使用發送反饋——無需 GitHub 帳號。

  • 郵件支援

    不適合公開討論的事情，比如私人問題，可以發郵件。

    support@mindwtr.app

加入討論。

在 Discord 上和其他使用者以及開發者聊聊。報告問題和功能建議請用 GitHub，那裡一切都可追蹤、可搜尋。社群也自發經營著一個 r/Mindwtr 討論區。

加入 Discord GitHub Issues r/Mindwtr

想在經濟上支援 Mindwtr？

這從來不是必須的——Mindwtr 無論如何都免費。但如果它幫你節省了時間，你也願意出一份力，這裡有一個專門的頁面。如果你代表企業，可以檢視贊助計劃。
