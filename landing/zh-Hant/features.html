從想法到完成

記錄惦記的事，想清楚下一步，並定期更新清單。 剛接觸 GTD？從這裡開始 →

  • 收集 →

    隨時隨地快速新增——全域快速鍵、托盤、分享選單或語音。

  • 理清 →

    引導式清理收集箱，內建兩分鐘法則。

  • 組織 →

    專案、分組、情境和狀態清單。

  • 回顧 →

    每日和每週回顧流程，帶提醒。

  • 執行 →

    按情境篩選的下一步行動，讓你永遠知道接下來做什麼。

找到現在需要的任務

在下一步行動、專案、行事曆和看板之間切換。

  • 專注 →

    按時間排列的日程和你的下一步行動，同屏呈現。

  • 專案 →

    多步驟目標，支援分組、領域和手動排序。

  • 日曆 →

    安排有日期的工作，並訂閱外部日曆和 ICS 日程源。

  • 看板 →

    看板式拖放，在收集箱、下一步、等待中、將來/也許之間移動任務。

  • 情境與標籤 →

    按做事的場合給任務打標籤，比如 @家裡 或 @工作/會議；巢狀情境會歸入上級情境。

  • 回顧 →

    每日和每週回顧精靈，讓系統始終可信。

日常任務工具

查找筆記、錄下想法、重複例行任務，或開啟專注計時。

  • 全域搜尋 →

    搜尋任務、筆記和專案，需要時再用篩選條件縮小範圍。

  • 語音記錄 →

    說出一個任務，它會被自動轉成文字並放進你的收集箱。

  • 番茄鐘專注 →

    用可選的計時器安排專注時間和休息。

  • 可複用清單 →

    複製任務或重置檢查清單，應對一遍遍重複的日常流程。

  • 附件與筆記 →

    任何任務都能附上檔案、連結和支援預覽的 Markdown 筆記。

  • 彈性重複 →

    下一次日期在你完成後才計算，而不是按死板的固定週期。

自己掌握資料

匯入任務、保留備份，自行選擇是否同步以及同步到哪裡。

  • 在你的裝置上 →

    任務、筆記、專案和附件都從你的裝置開始（本地優先）。

  • 靈活同步 →

    選擇 iCloud、Dropbox、資料夾、WebDAV 或自己的同步伺服器。

  • 匯入 →

    從 Todoist、TickTick、DGT GTD 或 OmniFocus 遷移你的任務。

  • Obsidian →

    匯入倉庫，並保留跳回原筆記的深層連結（桌面端）。

  • 外部日曆 →

    讀取系統和 Apple 日曆，推送有日期的任務，並訂閱 ICS。

  • 備份與恢復 →

    匯出為 JSON，並從經過校驗的 Mindwtr 備份恢復。

按需連接其他工具

透過捷徑、AI 或指令碼處理任務。這些功能都可以不開啟。

  • AI 助手 →

    使用自己的服務商 API 憑證或本機模型。

  • 本地 REST API →

    基於權杖認證的 localhost API，用指令碼控制桌面應用。

  • MCP 伺服器 →

    讓相容的 AI 工具透過 Mindwtr 的 MCP 服務讀取和管理任務。

  • Apple 快捷指令與 Siri →

    在 Apple 裝置上自動化收集和各種操作。

  • 網頁應用（PWA） →

    瀏覽器直接存取，支援離線。

  • Docker →

    用 Docker 執行 PWA 和自建同步伺服器。

在電腦、手機和手錶上使用

在桌面和行動裝置上記錄、規劃和回顧任務。下方可查看各裝置支援的功能。

  • 桌面端 →

    macOS、Windows 和 Linux。

  • 行動版 →

    iOS 和 Android，提供完整引導流程，並支援透過分享選單、語音和小工具收集。

  • Apple Watch →

    在手腕上透過語音或文字記錄、處理專注任務和控制番茄鐘。從下一個穩定版開始包含。

  • 鍵盤 →

    Vim 和 Emacs 鍵位預設，純鍵盤高效操作。

  • 主題 →

    淺色與深色，跟隨系統。

  • 20 種語言 →

    在設定中選擇語言，完整清單見文件。
