¿Necesitas ayuda con Mindwtr?

Busca una guía, informa de un problema o escríbenos en privado. Para un error, indica tu dispositivo y la versión de la app en Ajustes → Acerca de.

Elige cómo obtener ayuda.

Usa una guía para configurar la app, los comentarios en la app si no tienes GitHub o un issue para un error público.

  • Consulta las guías

    Instalación, sincronización, importación y preguntas frecuentes.

    Primeros pasos Preguntas frecuentes

  • Abrir un issue en GitHub

    Para errores y propuestas que quieras comentar públicamente.

    Abrir un issue →

  • Enviar comentarios desde la app

    ¿Ya estás en la app? Usa Enviar comentarios en la página Acerca de (Ajustes → Acerca de); no hace falta cuenta de GitHub.

  • Soporte por correo

    Para preguntas o detalles que prefieras mantener en privado.

    support@mindwtr.app
