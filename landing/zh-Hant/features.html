Mindwtr 能做的一切。

一個完整的系統，深度功能平時不打擾你，需要時隨手可得。下面是按你想做的事分組的完整全貌，每個部分都連結到文件裡的具體用法。

看看 Mindwtr 和其他應用的對比 →

GTD，從頭到尾

收集、理清、組織、回顧、執行。Mindwtr 讓各個步驟環環相扣，而不是變成一件件孤立的雜務。剛接觸 GTD？從這裡開始 →

  • 收集 →

    隨時隨地快速新增——全域快速鍵、托盤、分享選單或語音。

  • 理清 →

    引導式清理收集箱，內建兩分鐘法則。

  • 組織 →

    專案、分組、情境和狀態清單。

  • 回顧 →

    每日和每週回顧流程，帶提醒。

  • 執行 →

    按情境篩選的下一步行動，讓你永遠知道接下來做什麼。

系統的每個部分都有對應的檢視

每個檢視都為 GTD 方法而設計，而不是事後拼湊。

  • 專注 →

    按時間排列的日程和你的下一步行動，同屏呈現。

  • 專案 →

    多步驟目標，支援分組、領域和手動排序。

  • 日曆 →

    安排有日期的工作，並訂閱外部日曆和 ICS 日程源。

  • 看板 →

    看板式拖放，在收集箱、下一步、等待中、將來/也許之間移動任務。

  • 情境與標籤 →

    按做事的場合給任務打標籤，比如 @家裡 或 @工作/會議；巢狀情境會歸入上級情境。

  • 回顧 →

    每日和每週回顧精靈，讓系統始終可信。

深度功能，需要時才出現

強大的功能平時不打擾你，需要時才登場。

  • 全域搜尋 →

    支援 status:、context:、due:<=7d 等運算子，搜遍所有內容。

  • 語音記錄 →

    說出一個任務，它會被自動轉成文字並放進你的收集箱。

  • 番茄鐘專注 →

    專注檢視內建 15/3、25/5、50/10 計時器，還可以自訂一組。

  • 可複用清單 →

    複製任務或重置檢查清單，應對一遍遍重複的日常流程。

  • 附件與筆記 →

    任何任務都能附上檔案、連結和支援預覽的 Markdown 筆記。

  • 彈性重複 →

    下一次日期在你完成後才計算，而不是按死板的固定週期。

你的資料，按你的方式

任務留在你的裝置上。同步是可選的，同步到哪裡由你決定。無需帳號。

  • 在你的裝置上 →

    任務、筆記、專案和附件都從你的裝置開始（本地優先）。

  • 靈活同步 →

    Apple 裝置上原生 iCloud/CloudKit，另有檔案同步、WebDAV、Dropbox 和自建雲端。

  • 匯入 →

    從 Todoist、TickTick、DGT GTD 或 OmniFocus 遷移你的任務。

  • Obsidian →

    匯入倉庫，並保留跳回原筆記的深層連結（桌面端）。

  • 外部日曆 →

    讀取系統和 Apple 日曆，推送有日期的任務，並訂閱 ICS。

  • 備份與恢復 →

    匯出為 JSON，並從經過校驗的 Mindwtr 備份恢復。

進階能力，留給愛折騰的人

AI 和自動化始終是可選項——想用再啟用。

  • AI 助手 →

    接入你自己的 OpenAI、Gemini 或 Claude 帳號，或執行本地/自建模型。

  • 本地 REST API →

    基於權杖認證的 localhost API，用指令碼控制桌面應用。

  • MCP 伺服器 →

    透過已發布的 mindwtr-mcp 伺服器，從 LLM 客戶端操控 Mindwtr。

  • Apple 快捷指令與 Siri →

    在 Apple 裝置上自動化收集和各種操作。

  • 網頁應用（PWA） →

    瀏覽器直接存取，支援離線。

  • Docker →

    用 Docker 執行 PWA 和自建同步伺服器。

在哪工作都是原生體驗

每臺裝置上都是同一套系統，用你的語言。

  • 桌面端 →

    macOS、Windows 和 Linux。

  • 行動版 →

    iOS 和 Android，外加 Android 主螢幕專注小工具。

  • 鍵盤 →

    Vim 和 Emacs 鍵位預設，純鍵盤高效操作。

  • 主題 →

    淺色與深色，跟隨系統。

  • 20 種語言 →

    英語、簡體中文、繁體中文、印地語、西班牙語、阿拉伯語、法語、葡萄牙語、俄語、德語、日語、波斯語、越南語、土耳其語、韓語、義大利語、波蘭語、荷蘭語、捷克語和瑞典語。
