# 备份与恢复

Mindwtr 将工作数据保存在本地，并允许你导出 JSON 备份，以便携带、修复和迁移。

恢复被设计为**替换本地数据**的流程：

- 你选择一个备份 JSON 文件
- Mindwtr 在更改任何内容前先验证文件
- 如有可能，Mindwtr 会先创建恢复快照
- 所选备份替换当前本地数据集

这样能让恢复过程简单且可预期。它不是合并操作——若需要合并，请改用**合并备份**。

---

## 导出备份

### 桌面端

1. 打开**设置 → 数据**
2. 在**备份**中选择**导出备份**
3. 将 JSON 文件保存到所需位置

### 移动端

1. 打开**设置 → 数据**
2. 点按**导出备份**
3. 保存或分享 JSON 文件

备份格式与 Mindwtr 内部 `data.json` 结构兼容。

---

## 从备份恢复

### 桌面端

1. 打开**设置 → 数据**
2. 在**备份**中选择**恢复备份**
3. 选择 Mindwtr 备份 JSON 文件
4. 检查摘要并确认恢复

如果 Tauri 运行时可用，桌面端会在恢复前于本地快照目录中创建数据快照。

### 移动端

1. 打开**设置 → 数据**
2. 点按**恢复备份**
3. 选择 Mindwtr 备份 JSON 文件
4. 检查摘要并确认恢复

移动端会在恢复前于应用存储中保存本地恢复快照。

---

## 从备份合并

**合并备份**在两个平台上都位于“恢复备份”旁边，它会把备份文件与当前数据合并，而不是替换。合并规则与同步一致：

- 只存在于备份中的条目会被添加
- 两边都有时，较新的一方胜出
- 只存在于本设备的条目会保留
- 你在本设备上删除的条目仍保持删除状态，即使备份中还有一份未删除的副本

合并完成后，Mindwtr 会报告添加和更新了多少任务。如有可能，会先保存恢复快照，因此合并可以像恢复一样撤销。

如果想把第二个 Mindwtr 实例（工作手机、出差用的笔记本）并入主实例，或在设备之间迁移改动而不清空任何一边，请使用合并。如果希望用备份替换设备上的内容，请使用恢复。

---

## 恢复快照

原生桌面端和移动端会在恢复备份和受支持的数据导入前自动创建恢复快照，包括“设置”中的导入和已确认的批量文本收集。浏览器/PWA 版本没有本地快照目录。

- **桌面端**：快照显示在**设置 → 同步 → 恢复快照**中
- **移动端**：快照显示在**设置 → 同步 → 恢复快照**中

如果恢复了错误文件，或想撤销本地导入/恢复操作，可使用这些快照。

快照只包含 Mindwtr 数据，无法恢复从其他应用中删除的源项目，包括导入后从 Apple 提醒事项中删除的提醒事项。

---

## 验证规则

Mindwtr 会在恢复前验证所选 JSON 文件：

- 文件必须是有效 JSON
- 必须符合 Mindwtr 的数据结构
- 可用时会显示项目数量和备份元数据
- 版本不匹配会产生警告，而不是无提示失败

验证失败时，恢复会被阻止，当前数据保持不变。

---

## 恢复不会执行的操作

- **不会**把备份与当前本地数据合并（这是**合并备份**的作用）
- **不会**只恢复一项任务或一个项目
- **不会**恢复你的附件文件 — 备份 JSON 只保存每个附件的元数据和路径，从不包含文件内容
- 在下一次同步周期前，**不会**自行覆盖远程同步服务

如果使用同步，请把恢复理解为先替换当前本地状态。之后的同步行为取决于所用后端，以及下一台执行同步的设备。

附件文件保存在备份之外，必须单独复制。在桌面端，它们位于 `mindwtr.db` 旁的 `attachments` 文件夹（各操作系统的路径请参阅[数据与同步](/zh-Hans/data-sync/)）。请连同 JSON 一起备份该文件夹，否则恢复后得到的附件条目将指向已不存在的文件。[附件](/zh-Hans/use/attachments)说明了哪些内容保存在何处。

---

## 恢复与同步

恢复被视为一次有意的决定，而不是又一次需要合并的修改：

- 备份中包含的记录会以高于远端的修订号写回，因此恢复后的版本会在下一次合并中胜出
- 执行恢复的设备曾经见过、但备份中没有的记录会被标记为已删除，远端便不会在下一次同步时把它们送回

第二点正是恢复能够生效的原因。否则，备份之后新建的内容仍然留在远端，下一次同步会把这种缺失当成新记录并将其恢复。

本设备从未见过的记录不受影响。如果在本设备离线期间，另一台设备创建了任务，在这里恢复备份不会删除它们。

由于恢复会把这些删除传播到所有同步设备，请在一台设备上恢复并等待其同步完成，再使用其他设备。

---

## 提示

- 除同步外，也请定期手动导出
- 只从你信任的备份恢复
- 如果使用文件同步，请等正确的 `data.json` 完成复制后，再同步另一台设备

另请参阅[数据与同步](/zh-Hans/data-sync/)。
