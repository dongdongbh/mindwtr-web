# 備份與還原

Mindwtr 將工作資料儲存在本機，也能匯出 JSON 備份，便於攜帶、修復及遷移。

還原是一種**取代本機資料**的流程：

- 由你選擇備份 JSON 檔案
- Mindwtr 會在變更任何內容前驗證檔案
- 可行時先建立復原快照
- 所選備份會取代目前的本機資料集

這讓還原保持簡單、可預期；它不是合併操作——若需要合併，請改用**合併備份**。

---

## 匯出備份

### 桌面版

1. 開啟**設定 → 資料**
2. 在**備份**中選擇**匯出備份**
3. 將 JSON 檔案存至所需位置

### 行動版

1. 開啟**設定 → 資料**
2. 點選**匯出備份**
3. 儲存或分享 JSON 檔案

備份格式與 Mindwtr 的內部 `data.json` 結構相容。

---

## 從備份還原

### 桌面版

1. 開啟**設定 → 資料**
2. 在**備份**中選擇**還原備份**
3. 選擇 Mindwtr 備份 JSON 檔案
4. 檢查摘要並確認還原

還原前，若 Tauri 執行階段可用，桌面版會在本機快照目錄建立資料快照。

### 行動版

1. 開啟**設定 → 資料**
2. 點選**還原備份**
3. 選擇 Mindwtr 備份 JSON 檔案
4. 檢查摘要並確認還原

還原前，行動版會在應用程式儲存空間保存本機復原快照。

---

## 從備份合併

**合併備份**在兩個平台上都位於「還原備份」旁邊，它會把備份檔案與目前資料合併，而不是取代。合併規則與同步一致：

- 只存在於備份中的項目會被加入
- 兩邊都有時，較新的一方勝出
- 只存在於本裝置的項目會保留
- 你在本裝置上刪除的項目仍維持刪除狀態，即使備份中還有一份未刪除的副本

合併完成後，Mindwtr 會回報加入與更新了多少任務。可行時會先保存復原快照，因此合併可以像還原一樣回復。

若想把第二個 Mindwtr 執行個體（工作手機、出差用的筆電）併入主要的那一個，或在裝置之間搬移變更而不清空任何一邊，請使用合併。若希望以備份取代裝置上的內容，請使用還原。

---

## 復原快照

原生桌面版與行動版會在還原備份及支援的資料匯入前自動建立復原快照，包括「設定」中的匯入與已確認的批次文字收集。瀏覽器／PWA 版本沒有本機快照目錄。

- **桌面版**：快照位於**設定 → 同步 → 復原快照**
- **行動版**：快照位於**設定 → 同步 → 復原快照**

若還原了錯誤檔案，或想回復本機的匯入／還原操作，可使用這些快照。

快照只包含 Mindwtr 資料，無法還原從其他應用程式刪除的來源項目，包括匯入後從 Apple 提醒事項中刪除的提醒事項。

---

## 驗證規則

Mindwtr 會在還原前驗證所選 JSON 檔案：

- 檔案必須是有效 JSON
- 必須符合 Mindwtr 的資料形狀
- 可用時會顯示項目數量與備份中繼資料
- 版本不符會顯示警告，而不會默默失敗

驗證失敗時，還原會遭阻止，目前資料維持不變。

---

## 還原不會執行的操作

- **不會**將備份與目前本機資料合併（那是**合併備份**的用途）
- **不會**只還原單一任務或專案
- 在下一次同步週期前，**不會**自行覆寫遠端同步服務

若使用同步，可將還原視為先取代目前的本機狀態；後續同步行為取決於所用後端及下一部執行同步的裝置。

---

## 還原與同步

還原被視為一次刻意的決定，而不是另一筆需要合併的變更：

- 備份中包含的記錄會以高於遠端的修訂號寫回，因此還原後的版本會在下一次合併中勝出
- 執行還原的裝置曾經見過、但備份中沒有的記錄會被標記為已刪除，遠端便不會在下一次同步時送回

第二點正是還原能夠生效的原因。否則，備份之後新建的內容仍留在遠端，下一次同步會把這種缺少當成新記錄並將其還原。

本裝置從未見過的記錄不受影響。若在本裝置離線期間，另一部裝置建立了任務，在這裡還原備份不會刪除它們。

由於還原會把這些刪除傳播到所有同步裝置，請先在一部裝置上還原並等待同步完成，再使用其他裝置。

---

## 提示

- 除同步外，也請定期手動匯出
- 只還原你信任的備份
- 使用檔案同步時，請等正確的 `data.json` 完成複製，再同步其他裝置

另請參閱[資料與同步](/zh-Hant/data-sync/)。
