# 可重复使用的清单（模板）

Mindwtr 支持可重复使用的检查清单，适合没有严格日程的重复事项（如打包、购物、出行准备）。

## 三种模式

### 复制（模板）

每次都需要一份全新副本时使用。

示例：**打包清单**

1. 在“将来/也许”中保留一项主任务
2. 计划出行时复制它
3. 编辑副本，不影响主任务

复制时会重置：

- 检查清单项目恢复为未勾选
- 清除完成状态；已完成或已归档任务的副本会进入**收件箱**，等待重新理清
- 副本不会进入“今日专注”
- 不复制文件附件；链接会被复制
- 副本成为一项新任务，拥有新的检查清单与附件 ID

会保留的内容：标题、描述、项目、分区、领域、情境、标签，以及开始、截止和回顾日期。重复任务会保留其规则，但会开启独立的循环序列，因此完成其中一份不再推进另一份。

### 重置检查清单

想再次使用同一份清单时使用。

示例：**购物清单**

1. 购物时勾选项目
2. 点按**重置检查清单**
3. 下次继续使用

重置会：

- 取消勾选所有检查清单项目
- 就地更新任务，而不是创建第二份副本
- 如果任务已标记完成，则重新打开它

### 复制项目（多任务模板）

当模板是整个项目而不是一份检查清单时使用。

示例：**客户入驻**

1. 保留一个包含分区和任务的主项目
2. 有新客户时复制该项目
3. 在副本上推进，主项目保持不变

复制项目会重置的内容：

- 副本命名为 `<Project> (Copy)`，排在同一领域的末尾，且不处于聚焦状态
- 每个复制的任务都回到**下一步**（参考任务仍为参考），并清除开始、截止、回顾与完成日期
- 复制任务中的检查清单项从未勾选开始，也不会进入今日聚焦
- 项目及其任务上的附件都会一并复制，并在下次同步时重新上传

会保留的内容：项目的备注、领域、标签、颜色和状态，以及完整的分区结构——每个任务都会回到它原来的分区。项目自身的截止日期和回顾日期会原样保留——不同于任务上的日期，它们不会被清除，因此请在副本上核对。已删除的任务和分区不会被复制。

## 在哪里找到

- **移动端**：任务编辑器 → **复制任务**或**重置检查清单**
- **桌面端**：任务操作菜单。“已完成”和“已归档”中的任务行在悬停时也会显示复制按钮。
- **项目**：桌面端在侧边栏右键点击项目，或使用项目标题栏 **...** 菜单中的**复制**。移动端向右滑动项目行，或使用项目详情页中的**复制**。

## 应该选择哪一种

- 出行准备、入门检查清单，或每次都应拥有独立笔记和时间安排的事项，请使用**复制任务**。
- 购物、周期维护，或同一项任务长期都能继续使用的清单，请使用**重置检查清单**。
- 如果清单还带有日期、重复规则或项目专属笔记，复制通常更稳妥。

## 提示

- 将主版本保存在**将来/也许**或干扰较少的项目中，以免占据日常清单。
- 如果经常复制模板式任务，可使用 `打包清单（模板）` 之类一目了然的名称。
- 如果检查清单中的每一项都开始需要截止日期或重复规则，请拆分为独立任务，不要让一份可重复使用的清单承载过多功能。
