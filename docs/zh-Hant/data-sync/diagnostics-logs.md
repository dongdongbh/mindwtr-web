# 診斷與日誌

Mindwtr 內建診斷日誌，可協助排查同步與當機問題。日誌**只儲存在本機**，敏感值在寫入前會先**遮蔽**。

---

## 使用範例資料錄影

選擇**設定 → 資料 → 開啟沙盒**，即可使用虛構的任務和專案體驗 Mindwtr。介面會持續顯示沙盒橫幅，提供重設範例資料和離開操作。行動版使用簡短的**沙盒**、**重設**和**離開**文字。

此選項位於診斷設定附近。進入前會顯示確認提示，說明沙盒用途；選擇**取消**即可留在個人工作區。

範例工作區包含不同狀態的任務、領域、專案與區段、重複任務、檢查清單、備註、標籤、情境、聯絡人，以及日期和優先順序範例。你可以在錄影時編輯這些範例。變更是暫時的，重設會重新載入原始範例資料。

範例內容支援英語、德語、法語、西班牙語、俄語和簡體中文。應用程式使用任一中文語言時，範例均為簡體中文；其他不支援的語言使用英語範例。

個人資料庫會分開保留。離開沙盒會返回個人工作區；沙盒開啟後重新啟動應用程式，也會返回個人工作區。進入前會等待正在進行的同步和本機寫入完成，切換期間會阻止應用程式發起新的同步。如果等待逾時或儲存失敗，你會留在個人工作區。沙盒中的變更不會同步，也不會更新小工具、手錶、提醒、外部行事曆或收集整合。

如果問題與特定任務、附件或同步歷史有關，範例資料可能無法重現。分享前請檢查錄影：沙盒不會隱藏作業系統通知或其他應用程式。

## 啟用除錯日誌

### 桌面版

1. 開啟**設定 → 資料**
2. 開啟**除錯日誌**
3. 重現問題

**發行版診斷組建**：只有以 `diagnostics` 功能建置桌面應用程式時，才能使用開發者工具與額外日誌。

```bash
cd apps/desktop
cargo tauri build --features diagnostics
MINDWTR_DIAGNOSTICS=1 ./src-tauri/target/release/mindwtr
```

### 行動版

1. 開啟**設定 → 資料**
2. 開啟**除錯日誌**
3. 重現問題

## 分享或清除日誌

### 桌面版

- 日誌檔案路徑顯示於**設定 → 資料**
- 也可在同一畫面清除日誌

### 行動版

- 使用**分享日誌**匯出日誌檔案
- 使用**清除日誌**移除舊項目

---

## 預設日誌位置（桌面版）

| 平台 | 日誌檔案 |
| --- | --- |
| Linux | `~/.local/share/mindwtr/logs/mindwtr.log` |
| Windows | `%APPDATA%/mindwtr/logs/mindwtr.log` |
| Windows (Microsoft Store) | `%LOCALAPPDATA%/Packages/<package>/LocalCache/Roaming/mindwtr/logs/mindwtr.log` |
| macOS | `~/Library/Application Support/mindwtr/logs/mindwtr.log` |

---

## 記錄內容

- 同步錯誤與步驟
- 衝突摘要：即使除錯日誌關閉，解決衝突的合併仍一律寫入 `mindwtr.log`，以便事後稽核。這些常駐項目包含記錄 ID、變更的欄位名稱及採用哪一端；絕不寫入記錄內容（標題、筆記）。
- 未預期的執行階段錯誤

敏感值（API 金鑰、token、密碼及含憑證的 URL）會自動遮蔽。
