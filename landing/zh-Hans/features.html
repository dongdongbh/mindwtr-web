从想法到完成

记录惦记的事，想清楚下一步，并定期更新清单。 刚接触 GTD？从这里开始 →

  • 收集 →

    随时随地快速添加——全局快捷键、托盘、分享菜单或语音。

  • 理清 →

    引导式清理收集箱，内置两分钟法则。

  • 组织 →

    项目、分组、情境和状态清单。

  • 回顾 →

    每日和每周回顾流程，带提醒。

  • 执行 →

    按情境筛选的下一步行动，让你永远知道接下来做什么。

找到现在需要的任务

在下一步行动、项目、日历和看板之间切换。

  • 专注 →

    按时间排列的日程和你的下一步行动，同屏呈现。

  • 项目 →

    多步骤目标，支持分组、领域和手动排序。

  • 日历 →

    安排有日期的工作，并订阅外部日历和 ICS 日程源。

  • 看板 →

    看板式拖放，在收集箱、下一步、等待中、将来/也许之间移动任务。

  • 情境与标签 →

    按做事的场合给任务打标签，比如 @家里 或 @工作/会议；嵌套情境会归入上级情境。

  • 回顾 →

    每日和每周回顾向导，让系统始终可信。

日常任务工具

查找笔记、录下想法、重复例行任务，或开启专注计时。

  • 全局搜索 →

    搜索任务、笔记和项目，需要时再用筛选条件缩小范围。

  • 语音记录 →

    说出一个任务，它会被自动转成文字并放进你的收集箱。

  • 番茄钟专注 →

    用可选的计时器安排专注时间和休息。

  • 可复用清单 →

    复制任务或重置检查清单，应对一遍遍重复的日常流程。

  • 附件与笔记 →

    任何任务都能附上文件、链接和支持预览的 Markdown 笔记。

  • 弹性重复 →

    下一次日期在你完成后才计算，而不是按死板的固定周期。

自己掌握数据

导入任务、保留备份，自行选择是否同步以及同步到哪里。

  • 在你的设备上 →

    任务、笔记、项目和附件都从你的设备开始（本地优先）。

  • 灵活同步 →

    选择 iCloud、Dropbox、文件夹、WebDAV 或自己的同步服务器。

  • 导入 →

    从 Todoist、TickTick、DGT GTD 或 OmniFocus 迁移你的任务。

  • Obsidian →

    导入仓库，并保留跳回原笔记的深层链接（桌面端）。

  • 外部日历 →

    读取系统和 Apple 日历，推送有日期的任务，并订阅 ICS。

  • 备份与恢复 →

    导出为 JSON，并从经过校验的 Mindwtr 备份恢复。

按需连接其他工具

通过快捷指令、AI 或脚本处理任务。这些功能都可以不开启。

  • AI 助手 →

    使用自己的服务商 API 凭据或本地模型。

  • 本地 REST API →

    基于令牌认证的 localhost API，用脚本控制桌面应用。

  • MCP 服务器 →

    让兼容的 AI 工具通过 Mindwtr 的 MCP 服务读取和管理任务。

  • Apple 快捷指令与 Siri →

    在 Apple 设备上自动化收集和各种操作。

  • 网页应用（PWA） →

    浏览器直接访问，支持离线。

  • Docker →

    用 Docker 运行 PWA 和自建同步服务器。

在电脑、手机和手表上使用

在桌面和移动设备上记录、规划和回顾任务。下方可查看各设备支持的功能。

  • 桌面端 →

    macOS、Windows 和 Linux。

  • 移动端 →

    iOS 和 Android，提供完整引导流程，并支持通过分享菜单、语音和小组件收集。

  • Apple Watch →

    在手腕上通过语音或文字记录、处理专注任务和控制番茄钟。从下一个稳定版开始包含。

  • 键盘 →

    Vim 和 Emacs 键位预设，纯键盘高效操作。

  • 主题 →

    浅色与深色，跟随系统。

  • 20 种语言 →

    在设置中选择语言，完整列表见文档。
